# Student Hub (Kotlin + XML Views)

Template type: Empty Views Activity. Open this folder in Android Studio (File > Open), let Gradle sync, then Run.

Layouts live in app/src/main/res/layout (open them and use the Design tab to drag and drop).
Screens: Home, Exams, Assignments, Tasks, Ideas, plus a Welcome screen and a profile panel (tap your name, top left).
Stack: XML + ViewBinding, Fragments, RecyclerView, Room, WorkManager.
Change the app color in res/values/colors.xml.
